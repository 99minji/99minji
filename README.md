# Hi, I'm Minji 👋

**Frontend Developer · React · React Native · TypeScript**

사용자가 마주하는 화면뿐 아니라, 그 화면을 움직이는 데이터와 상태, 예외 상황까지 함께 고민합니다.

운영 중인 서비스의 새로운 기능을 구축하고, 반복되는 문제를 공통 컴포넌트와 재사용 가능한 로직으로 개선해 왔습니다.

### What I focus on

- **Product UI** — 실제 사용 흐름을 고려한 웹·모바일 화면 개발
- **State & Data** — 사용자 권한, API 응답, 비동기 상태와 예외 상황 관리
- **Reusable Architecture** — 공통 컴포넌트, 커스텀 훅, 비즈니스 로직 분리
- **Reliable Delivery** — TypeScript 타입 검사, 단위 테스트, 실기기 검증
